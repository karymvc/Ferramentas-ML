Estes são os resultados do primeiro estudo comparativo entre as generalizações da integral de Choquet. 

Embora os dados completos não possam ser incluídos diretamente no corpo do trabalho devido à sua extensão, eles oferecem uma visão clara do 
comportamento de cada método em diferentes conjuntos de dados e métricas. A tabela permite observar padrões consistentes de desempenho, destacando
quais generalizações apresentam maior robustez ou estabilidade sob determinadas condições.
